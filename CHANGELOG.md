# Changelog

Todos los cambios relevantes de este proyecto se documentan aquí.
El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el proyecto usa [versionado semántico](https://semver.org/lang/es/).

## [1.0.0] - 2026-11-16

### Agregado

- Sitio bilingüe (español/inglés): Inicio, Nosotros, Servicios, 10 páginas de detalle de servicio, Contacto, Privacidad y 404.
- Sistema de marca: logo SVG (horizontal, vertical, isotipo, monocromo claro y oscuro), favicon con modo oscuro, íconos de app, manifest e imágenes Open Graph por página.
- Design tokens con modo claro/oscuro (`light-dark()`), selector manual de tema y tipografía Archivo autoalojada.
- Componentes accesibles: navegación con submenú, tarjetas, acordeón, formulario con validación accesible y honeypot, botón volver arriba.
- SEO: canonical, `hreflang`, Open Graph, JSON-LD, sitemap y robots.
- Calidad: html-validate, stylelint, eslint, prettier, pa11y-ci, verificación de enlaces, presupuesto de peso y Lighthouse CI.
- CI/CD con GitHub Actions y publicación en GitHub Pages.
